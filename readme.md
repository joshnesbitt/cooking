# Cooking Site


## Overview

A simple site to publish findings while cooking. Built with [Astro](https://astro.build/) and deployed to Netlify.


## Running

```
nvm use
npm install
npm run dev
```


## Building

```
npm run build
```

The static site is output to `dist/`.
